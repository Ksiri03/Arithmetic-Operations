# Legacy UI — version 1

This folder preserves the original editorial-style interface exactly as it was before the simplified student-friendly UI replaced it.

Files:

- `index.html`, `styles.css`, `app.js` — the original static frontend.
- `fonts/` — the Newsreader, Archivo and IBM Plex Mono files used by that design.

The original version is also available from Git:

```powershell
git checkout legacy-ui-v1
```

The matching lab write-up is preserved in [`docs/legacy/`](../../docs/legacy/).
